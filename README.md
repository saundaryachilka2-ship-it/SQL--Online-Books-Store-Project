Online Book Store - SQL Project

Project Overview

This project is based on an Online Book Store database. I used SQL to manage and analyze data related to books, customers, and orders.

Database Tables

BOOKS: Stores information about books.

CUSTOMERS: Stores customer information.

ORDERS: Stores order details.

Tools Used

PostgreSQL

pgAdmin

SQL

SQL Concepts Practiced

SELECT and WHERE

ORDER BY

GROUP BY and aggregate functions

JOINS

Subqueries

Sorting and filtering data

Solving SQL practice questions

Project Objectives

Retrieve information about books, customers, and orders.

Solve SQL questions using the database tables.

Practice joining tables to analyze related data.

Improve SQL query-writing and problem-solving skills.

What I Learned

Through this project, I practiced writing SQL queries, working with multiple related tables, and retrieving useful information from a database.
